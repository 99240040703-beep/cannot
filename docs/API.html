IMEI Guardian API

All API routes are prefixed with /api. Authenticated endpoints require Authorization: Bearer <JWT>.

Authentication

  • POST /api/auth/register — name, email, password (10+ characters)
  • POST /api/auth/login — email, password
  • GET /api/me — current account

Devices

  • GET /api/devices
  • POST /api/devices — name, IMEI, brand, model
  • POST /api/devices/:id/heartbeat — battery
  • POST /api/devices/:id/location — latitude, longitude, accuracy, battery
  • GET /api/devices/:id/locations
  • PATCH /api/devices/:id/lost-mode — enabled
  • POST /api/devices/:id/unlink

Account

  • GET /api/notifications
  • POST /api/notifications/:id/read
  • DELETE /api/account
  • GET /healthz

Location writes are owner-authenticated. The Android companion source in this repository is a starter scaffold and does not yet upload location. IMEI itself cannot query mobile networks or GPS.
